# Politique de sécurité

## Versions prises en charge

Seule la dernière version de la branche `main` reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

N’ouvrez pas d’issue publique pour une vulnérabilité non corrigée. Utilisez de préférence la fonction « Report a vulnerability » de l’onglet Security du dépôt GitHub. Si elle n’est pas disponible, contactez le mainteneur via son profil GitHub en demandant un canal privé, sans publier les détails sensibles.

Indiquez la version concernée, les conditions de reproduction, l’impact estimé et, si possible, une piste de correction. N’incluez aucun identifiant BetaSeries réel.

Un accusé de réception sera fourni dès que possible. La publication coordonnée du correctif sera discutée avec la personne ayant effectué le signalement.
